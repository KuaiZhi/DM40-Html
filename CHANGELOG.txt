# 更新日志
本日志记录网页版本的功能变化。版本边界以网页端开发过程为准。

2026.9.1
## 1.1 - 实时波形与交互完善

- 新增 Canvas 实时波形，使用 DM40 解析后的规范化测量值绘制。
- 波形支持最大值/最小值显示、封闭边框、36px 方形网格和橙色细曲线。
- 波形按可视宽度保存采样；填满右侧后立即移除最旧点并向左滚动。
- 模式切换或断开连接时立即清空波形，避免不同模式或单位的样本混合。
- 新增“实时波形”和“原始数据”折叠功能，默认收起；折叠不会停止 BLE 读取、解析、采样或日志记录。
- 原始数据窗口固定高度，只有查看位置已在底部时才自动跟随新日志。
- 将模式切换改为待发送队列：当前请求完成后优先发送模式命令，减少 DM40 忽略切换命令的情况。
- 新增中英文切换，覆盖标题、操作按钮、状态、提示和模式标签。
- 英文模式使用 VDC、VAC、ADC、Ω、Ωon、CAP、DIODE、CONT、Hz、℃ 等仪表常用标记；中文模式保留中文功能名称。
- 调整主题为 DM40 风格橙色深色界面，并优化按钮、文本光标和移动端布局细节。
- 充电状态移至电池信息区域；测量值区域仅显示 HOLD 状态。

2026.8.31
## 1.0 - Web Bluetooth 基础上位机

- 在独立 `html/` 目录中创建纯 HTML/CSS/JavaScript 网页版本，原 Python 工程保持只读参考用途。
- 使用 Web Bluetooth 连接 DM40 的 `fff0` 服务，订阅 `fff1` 通知特征并向 `fff3` 写入命令。
- 实现浏览器扫描、用户选择设备后自动连接、断开连接和自动连续轮询。
- 实现 DM40 命令校验和、原始 TX/RX 日志与 CRC 检查。
- 从 Python 版本移植主测量包解析：模式、量程、主读数、单位、电池、充电和 HOLD 状态。
- 修正 17 字节 DM40 测量包的负索引量程字节处理。
- 实现网页与仪表的模式同步和六个模式组循环切换：电压、电流、电阻、电容、二极管/通断、频率/温度。
- 完成基础测量界面、设备信息、电量显示和 DM40 橙色深色主题。
