# DM40 Web 上位机

基于 Web Bluetooth 的 DM40 系列万用表网页上位机。网页直接通过 BLE GATT 连接仪表，在 Edge 中查看实时读数、切换测量模式和绘制波形。

网页版本的全部代码位于本 `html/` 目录；仓库其余 Python 代码仅作为协议与功能参考，未被网页版本修改。

## 功能

- 通过浏览器设备选择器扫描并连接 DM40 BLE 设备。
- 连接成功后自动连续读取测量数据。
- 解析主读数、单位、量程、电量、充电和 HOLD 状态。
- 支持直流/交流/交直流电压与电流、电阻/在线电阻、电容、二极管/通断、频率/温度模式。
- 网页和仪表双向同步：仪表切换模式时网页按钮更新；网页切换时仪表同步切换。
- 串行化 BLE 请求，避免轮询命令和模式切换命令互相竞争。
- 实时波形、最大值/最小值、方形网格与自动滚动。
- 原始 TX/RX 数据与 CRC 结果记录。
- 波形和原始数据面板可折叠，折叠时仍持续采样和记录。
- 中英文界面切换，以及 DM40 风格橙色深色主题。

## 在线使用

请使用支持 Web Bluetooth 的 Edge 浏览器，并通过 HTTPS 地址访问：

```text
https://kuaizhi.github.io/DM40-Html/
```

使用步骤：

1. 打开网页，确认系统蓝牙和仪表均已开启。
2. 点击“扫描设备”。
3. 在 Edge 弹出的设备选择器中选择仪表，例如 `dm40x`、`DM40A`、`DM40B` 或 `DM40C`。
4. 网页会自动连接，并在收到设备信息后开始连续读取。
5. 点击六个模式键可在网页端切换测量模式；按仪表实体键时网页也会跟随更新。

## 使用要求与限制

- Web Bluetooth 只能在安全上下文中使用。GitHub Pages 的 HTTPS 地址可直接使用。本地调试请使用edge作为打开方式。
- 目标环境为支持 Web Bluetooth 的 浏览器，如Microsoft  Edge，手机移动端与PC端均可。其他浏览器可能影响功能可用性。
- 同一时间请只让一个客户端连接仪表，连接网页前应关闭原 Python 上位机或其他蓝牙客户端。
- 设备选择器由浏览器提供。网页不能像原生应用一样自行列出所有附近蓝牙设备。
- 当前型号显示的是浏览器返回的蓝牙名称；尚未通过设备 ID 响应识别具体的 DM40x型号。
- 部分未采集到的特殊量程或协议变体仍可能需要补充解析映射。

## BLE 接口

```text
Service: 0000fff0-0000-1000-8000-00805f9b34fb
Notify:  0000fff1-0000-1000-8000-00805f9b34fb
Write:   0000fff3-0000-1000-8000-00805f9b34fb
```

网页会为 DM40 命令自动计算校验和，订阅通知特征，并依照“发送一条请求、等待一条通知”的顺序持续轮询。
